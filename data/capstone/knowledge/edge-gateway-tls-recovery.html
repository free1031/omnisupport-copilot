Northstar Edge Gateway TLS and connectivity recovery

Applies to Edge Gateway firmware 3.8 and 3.9. Error codes: EG-CONN-001, EG-CERT-005, EG-BOOT-004.

Observed failure

The gateway rejects upstream TLS connections after an intermediate certificate expires. Logs contain certificate verify failed. Some devices remain offline after a network change.

Controlled recovery

  1. Export the current trust-store checksum and gateway configuration snapshot.
  2. Verify device time is within two minutes of the trusted NTP source.
  3. Install the renewed intermediate certificate; do not replace the private device identity key.
  4. Reload the trust store and test one canary gateway.
  5. Verify telemetry, command acknowledgement, and certificate chain before rolling out by site.

Rollback

If the canary cannot establish a trusted connection, restore the previous trust-store snapshot, reload the service, and attach the trace identifier to the incident. A factory reset is not an approved first response.

Escalation

Escalate to security when the leaf certificate identity does not match the registered device or when an unknown root certificate appears.
