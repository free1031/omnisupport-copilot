Workspace webhook delivery troubleshooting

Version 3.2. Support visibility: internal. Error codes: WS-WEBHOOK-005 and WS-API-404.

Symptom

A customer reports that a webhook endpoint receives no events, receives duplicate events, or returns HTTP 404 after a routing change.

排查顺序

  1. Verify the endpoint is HTTPS and resolves from the public internet.
  2. Check the delivery log for status code, attempt count, and request identifier.
  3. Confirm the subscribed event names and organization scope.
  4. Replay one delivery with the same event identifier. Consumers must deduplicate by event identifier.
  5. Rotate the signing secret only after the consumer accepts both current and next secrets.

Safety boundary

Support agents may replay a single failed delivery. Bulk replay, secret rotation, and endpoint ownership changes require a support lead. Webhook payloads may contain customer identifiers and must not be copied into public chat.

Success criteria

The endpoint returns a 2xx response within ten seconds, the delivery log records a completed attempt, and the consumer confirms exactly one business event.
